You see the device's screen on the computer and control it with mouse and keyboard. It takes less than a minute.

## Start mirroring {#start-mirroring}

1. Click the icon in the menu bar.
2. Point to the device.
3. Click :button[device.mirror]{icon=screencast}.

A window with the device's screen opens. The device gets a ▶ before its name in the menu, and the menu bar icon changes. You can :term[mirror] several devices at once.

## Stop mirroring {#stop-mirroring}

4. Point to the device in the menu.
5. Click :button[device.stopMirroring]{icon=screencast}. You can also close the window.

## If it does not work {#if-it-fails}

If the window closes at once, the app shows a message with the location of the log file. Read [Solve common problems](help:troubleshooting#mirroring-closes).
