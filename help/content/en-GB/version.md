We need the version number when you ask us for help. It takes a few seconds to find.

## In the menu {#about}

1. Click the icon.
2. Click :button[menu.about]{name="Appninjas ADB" icon=info}.

The window shows the version, links to the help and the source code, and the licences.

## In Terminal {#terminal}

3. Type `adb-tray --version` and press Return.

## Update {#update}

On a Mac: type `brew upgrade adb-tray`, then `brew services restart adb-tray`.

On Linux Mint, new versions arrive with the usual updates.
