You save a picture of the device's screen or open a command line on the device. It takes a few seconds.

## Take a screenshot {#screenshot}

1. Point to the device in the menu.
2. Click :button[device.screenshot]{icon=camera}.

The picture is saved in your Pictures folder. A message shows the file name.

## Open adb shell {#shell}

3. Point to the device in the menu.
4. Click :button[device.shell].

A terminal window opens with a command line on the device. Type `exit` to close it.

## If it does not work {#if-it-fails}

If the screenshot fails: unlock the device and try again.
