# Glossary

- **adb**: adb is Google's program that lets the computer talk to an Android device, by cable or over Wi-Fi.
- **scrcpy**: scrcpy is a free program that shows the device's screen in a window on the computer.
- **mirror**: To mirror means that the device's screen is shown in a window on the computer, and you can control it from there.
- **USB debugging**: USB debugging is a setting on the device that lets the computer control it through the cable.
- **wireless debugging**: Wireless debugging is the same as USB debugging, but over Wi-Fi.
- **menu bar**: The menu bar is the strip at the top of the Mac's screen. Appninjas ADB has an icon at its right end.
- **system tray**: The system tray is the icons in one corner of the panel in Linux Mint.
- **Homebrew**: Homebrew installs programs on a Mac with a command in Terminal.
- **Terminal**: Terminal is the program where you type commands. On a Mac it is in Applications, Utilities.
